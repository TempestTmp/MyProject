## Инструментарий
**Компилятор**: MinGW

**Процессор**: 13th Gen Intel(R) Core(TM) i5-13500H, 2600 МГц, ядер: 12, потоков: 16

**ОС**: Майкрософт Windows 11 Домашняя для одного языка


## Что реализовано
Реализован генератор псевдослучайных чисел: MyXorshiftGen

Найдена формула фигуры: x^4 - a * x^3  + (a * a) * (y * y + z * z) = 0

![формула фигуры](/assets/newFigura.png)


Реализована однопоточная реализация (без OpenMP):  single_threaded_implementation()

Реализована многопоточная реализация с автоматическим распределением работы между потоками: automatic_multithreaded_static(), automatic_multithreaded_dynamic()

Реализована многопоточная реализация, где OpenMP используется только для создания потоков, но не распределения работы между ними: multithreaded_dynamic(), multithreaded_static()

 Также было реализовано: обработка ошибок
# Описание:

**Генератор псевдослучайных чисел:**

Выбор генератора псевдослучайных чисел происходил из следующих простых генераторов: 

1) Линейный конгруэнтный генератор (LCG):

````c++
const long randMax = 4294967296;
state = 214013 * state + 2531011;
state ^= state >> 15;
return (uint) (state % randMax);
````

2) XorShift:

````c++
state ^= state << 13;
state ^= state >> 17;
state ^= state << 5;
return state;
````

3) Вихрь Мерсенна.

Мною был выбран генератор XorShift из-за его простоты и быстродействия.
